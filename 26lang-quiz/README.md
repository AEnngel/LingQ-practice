# 26개 언어 학습 테스트 (26lang-quiz)

26개 언어(한국어·영어 RP·코크니·스코츠어·독일어·프랑스어·스페인어·포르투갈어·이탈리아어·라틴어·
네덜란드어·아일랜드어·덴마크어·노르웨이어·스웨덴어·아이슬란드어·핀란드어·헝가리어·폴란드어·
우크라이나어·러시아어·그리스어·아프리칸스어·일본어·중국어(보통화)·광둥어)로 푸는 학습 테스트
웹 앱입니다. 휴대폰에서 바로 열 수 있는 정적 사이트이며, GitHub Pages로 배포됩니다.

- 사이트: <https://aenngel.github.io/LingQ-practice/26lang-quiz/>

## 탭 구성

| 탭 | 내용 |
|---|---|
| 📖 문법 | **공부하기**(가이드 21종 본문·표·예문을 앱에서 바로 읽고 예문 듣기) + **문제 풀기**(문장 순서 배열 · 빈칸 4지선다 · 어순 고르기 · 동사 변화) |
| 📝 단어 | 단어 4,860개 × 26개 언어 · 뜻→원어 / 원어→뜻 4지선다, 플래시카드, 주제·범위 필터 |
| 💬 내 문장 | Drops 화면으로 보내준 문장·표현 910개로 뜻 맞히기 / 원어 맞히기 / 플래시카드 |
| 📚 자료실 | PDF 78개(단어장 48권·문법 가이드 21종·동사 변화표 3권·한국어 레벨 테스트 6종) 모아 보기 |

## 기능

- 4지선다 자동 채점, 스스로 채점하는 문법 서술형 문제(정답·해설 보기)
- 플래시카드(앞: 뜻 / 뒤: 원어·한국어 발음·뜻)
- 한국어 발음 보기/숨기기, 중국어 성조·병음 보기/숨기기 토글
- 결과 화면의 정답률·문항별 다시 보기, **오답 노트**(localStorage 저장, 틀린 문제만 다시 풀기)
- 단어 범위: 전체 / 보내주신 단어 / IELTS·TOEFL 보완, 주제(380개) 검색
- 자료실: 카테고리 필터·검색·바로 열기/다운로드
- 🔎 **공부하기 검색**: 가이드 안의 파트 제목·설명·표·예문(원어·발음·뜻)을 실시간으로 찾아 주고, 몇 개 항목·몇 개 파트에서 맞았는지 보여 줌(✕로 바로 전체 보기)
- 🔍 **동사 변화 검색**: 동사 변화 화면에서 동사 원형(`to go`)·한국어 뜻(`가다`)·활용형(`ich bin`)·한국어 발음(`이히 빈`)으로 1~3권 전체를 찾아, 동사별 카드에 시제·인칭·활용형·발음·영어/한국어 문장을 모아 보여 주고 🔊로 바로 듣기. 「이 동사 풀기」로 그 동사만 4지선다 풀기
- 🔍 **문법 공부 모드**: 영어(RP)·영어(코크니)·스코틀랜드·스페인어·독일어·프랑스어·이탈리아어·포르투갈어·네덜란드어·아일랜드어·그리스어·폴란드어·러시아어·덴마크어·노르웨이어·스웨덴어·아이슬란드어·핀란드어·헝가리어·라틴어·우크라이나어 가이드의 파트별 설명·표·예문(예문마다 🔊 듣기, 파트 목차 이동)
- 🧩 **문법 문제 풀기**: 한국어 뜻을 보고 단어 칩을 순서대로 눌러 문장을 만드는 **어순 배열**, 가이드 예문·내 문장에서 낸 **빈칸 4지선다**, 같은 단어를 섞어 놓은 보기 중 바른 어순을 고르는 **어순 고르기**, 26개 언어 **동사 변화 4지선다** — 모두 즉시 채점·해설·발음·듣기 지원
- 🔊 **원어 듣기**: 문제·보기·정답·플래시카드의 원어를 기기 음성(TTS)으로 읽어 주고, 배속 **0.5x / 1x / 1.5x / 2x**를 고를 수 있음(선택값은 브라우저에 저장)

## 음성 듣기

- `window.speechSynthesis`(기기 내장 음성)를 사용합니다. 기기에 그 언어 음성이 없으면 조용히 넘어가지 않고 안내 문구가 뜹니다.
  (안드로이드: 설정 › 언어 및 입력 › 텍스트 읽어주기 › 음성 데이터 설치)
- 언어 코드: 영어 RP·코크니 `en-GB`, 스코츠어 `sco`(없으면 en-GB), 독일어 `de-DE`, 프랑스어 `fr-FR`,
  스페인어 `es-ES`, 포르투갈어 `pt-PT`(없으면 pt-BR), 이탈리아어 `it-IT`, 라틴어 `la`(없으면 it-IT),
  네덜란드어 `nl-NL`, 아일랜드어 `ga-IE`, 덴마크어 `da-DK`, 노르웨이어 `nb-NO`, 스웨덴어 `sv-SE`,
  아이슬란드어 `is-IS`, 핀란드어 `fi-FI`, 헝가리어 `hu-HU`, 폴란드어 `pl-PL`, 우크라이나어 `uk-UA`,
  러시아어 `ru-RU`, 그리스어 `el-GR`, 아프리칸스어 `af-ZA`, 일본어 `ja-JP`, 중국어 `zh-CN`,
  광둥어 `zh-HK`(없으면 yue·zh-CN)
- 중국어·광둥어는 병음·한글 발음이 섞이지 않도록 원어(한자)만 읽습니다. 문법 공부의 예문도 한국어 발음 줄을 빼고 원어만 읽습니다.
- 재생 중인 🔊 를 다시 누르면 정지합니다.
- **안드로이드(갤럭시·삼성 인터넷·크롬)**: 탭한 그 순간(사용자 제스처 안)에 바로 `speak()`를 부르고, 음성 목록이 비어 있거나 그 언어 음성이 없어도 `u.lang`만 지정해 기기 기본 엔진으로 재생을 시도합니다. 그래도 소리가 막히면 “앱 내 브라우저에서는 소리가 막힐 수 있어요 — 오른쪽 위 ⋮에서 크롬/삼성 인터넷으로 열기” 안내가 뜨고, 앱 안 브라우저(WebView)로 열린 경우에는 화면 위에 같은 안내 배너가 나옵니다.

## 데이터

데이터는 언어·모드별로 나뉜 JSON을 필요할 때 `fetch`합니다(`data/`).

```
data/vocab/meta.json        26개 언어, 주제 380개, 차수별 출처
data/vocab/items.json       4,860개 항목 [차수, 주제번호, 한국어, 영어, 문장여부]
data/vocab/l01~l26.json     언어별 [원어, 한국어 발음] (items.json과 같은 순번)
data/grammar/lingq/*.json   문법 가이드 21종 연습문제·정답·해설
data/grammar/study/*.json   문법 공부 모드 21종 본문(파트·문단·표·예문)
data/grammar/study/index.json  공부 모드 가이드 목록
data/grammar/games/{02~26}.json  언어별 문장 순서·빈칸·어순 고르기 문제
data/grammar/games/index.json   언어별 문제 수
data/grammar/verbs/         동사 변화 1~3권 (항목 630 × 26개 언어)
data/library.json           자료실 PDF 목록(제목·쪽수·용량)
```

개인정보(연락처·이메일·여행 일정 등)는 포함하지 않았습니다.
