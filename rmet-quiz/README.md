# 눈으로 감정 읽기 · RMET 78단어 · 7개 언어

RMET(Reading the Mind in the Eyes Test) 36문항의 선택지에 쓰인 감정 단어 78개를
**영어 · 고전 라틴어 · 이탈리아어 · 유럽식 포르투갈어 · 프랑스어 · 유럽식 스페인어 · 독일어**로
퀴즈와 카드로 익히는 페이지입니다.

- 주소: https://aenngel.github.io/LingQ-practice/rmet-quiz/
- 퀴즈: 언어(7개 / 랜덤) × 유형(외국어→한국어 뜻, 한국어 뜻→외국어) × 범위(전체·20개씩·별표만), 4지선다, 음성 자동 재생, 자동 다음 문제, 오답 자동 별표
- 카드: 78개 단어의 7개 언어 어형·순수 한글 발음·명사(정관사·성별), 검색, 별표 필터, 전체/별표 이어 듣기와 배속(0.7~2.0x)
- 음성: 기기 TTS. 영어 en-GB(영국식), 라틴어는 이탈리아어 음성으로 읽고, iOS의 로봇 성우(Sandy·Shelley·Eddy·Flo 등)는 선택에서 제외
- 저장: 별표·설정은 브라우저 localStorage
