# 프리미어 프로(Premiere Pro) 릴스 제작 왕초보 완전정복 가이드

> 참고 영상(`@yuyenwng` 리스본 여행 릴스) 스타일을 기준으로, **마우스 클릭 한 번부터 완성 파일 저장까지** 순서대로 따라 할 수 있게 정리한 매뉴얼입니다.
> *(단축키는 맥북 기준 `Cmd / Option`으로 적었고, 윈도우용은 괄호 안에 `Ctrl / Alt`로 함께 적었습니다.)*

---

## 0단계: 프로그램 켜고 새 작업실 만들기

1. 프리미어 프로를 실행합니다.
2. 왼쪽 위에 있는 파란색 **`New Project`(새 프로젝트)** 버튼을 **마우스 왼쪽 클릭**합니다.
3. 오른쪽 위 **`Project Name`(프로젝트 이름)** 칸을 클릭하고 `릴스_연습`이라고 적습니다.
4. 바로 아래 **`Project Location`(프로젝트 위치)** 을 눌러 바탕화면이나 원하는 폴더를 고릅니다.
5. 오른쪽 아래 파란색 **`Create`(만들기)** 버튼을 클릭합니다. *(왼쪽에 영상 파일 고르라는 화면이 나와도 일단 무시하고 바로 `Create` 누르셔도 됩니다.)*

---

## 1단계: 화면 구조 4칸만 외우기

작업 화면이 열렸을 때 창 위치가 이상하면, 화면 맨 위 메뉴바에서 **`Window(창)` → `Workspaces(작업 영역)` → `Editing(편집)`** 을 차례로 클릭합니다. 화면이 딱 4등분으로 정리됩니다.

1. **왼쪽 아래 (`Project` 프로젝트 패널)**: 내가 찍은 영상, 음악, 효과음을 담아두는 **재료 바구니**입니다.
2. **오른쪽 아래 (`Timeline` 타임라인 패널)**: 재료를 시간 순서대로 줄 세우고 자르는 **도마(작업대)** 입니다.
   - `V1, V2, V3`: **영상(Video) 층**입니다. 숫자가 높을수록(위층일수록) 화면 맨 앞에 보입니다.
   - `A1, A2, A3`: **소리(Audio) 층**입니다. 여러 층에 소리를 쌓으면 동시에 섞여서 들립니다.
3. **오른쪽 위 (`Program` 프로그램 모니터)**: 지금 만들고 있는 영상이 실제로 어떻게 재생되는지 보는 **TV 화면**입니다.
4. **왼쪽 위 (`Effect Controls` 효과 컨트롤 패널)**: 타임라인에서 영상 조각 하나를 클릭했을 때, 크기·위치·밝기 등을 조절하는 **리모컨**입니다. *(안 보이면 상단 메뉴 `Window` → `Effect Controls` 클릭)*

---

## 2단계: 재료 불러오고 인스타 세로 화면(9:16) 만들기

### ① 영상·음악·효과음 불러오기
1. **왼쪽 아래 (`Project` 패널)** 의 회색 빈 공간을 마우스 왼쪽 버튼으로 **빠르게 두 번 클릭(더블클릭)** 합니다.
2. 파일 선택 창이 뜨면, 쓸 영상 클립들 + 배경음악 + 효과음을 마우스로 드래그해서 모두 선택한 뒤 **`Import`(가져오기)** 를 누릅니다.

### ② 세로 릴스 도화지(시퀀스) 만들기
1. 상단 메뉴바 **`File(파일)` → `New(새로 만들기)` → `Sequence...(시퀀스...)`** 클릭 (단축키: `Cmd + N` / `Ctrl + N`).
2. 창이 열리면 맨 위 탭 중 **`Settings`(설정)** 글자를 클릭합니다.
3. **`Editing Mode`(편집 모드)** 를 클릭해서 맨 위 **`Custom`(사용자 정의)** 으로 바꿉니다.
4. **`Timebase`(시간 기준)**: **`30.00 frames/second`** 로 맞춥니다. (부드러운 60fps 영상이면 `60.00`)
5. **가장 중요! `Frame Size`(프레임 크기)**:
   - 왼쪽 칸(Horizontal/가로)에 **`1080`** 입력
   - 오른쪽 칸(Vertical/세로)에 **`1920`** 입력
   - 옆에 비율이 자동으로 `9:16`이 되면 성공입니다.
6. 맨 아래 `Sequence Name`에 `릴스_본편` 입력 후 **`OK`(확인)** 클릭!
7. **오른쪽 위 TV 화면(`Program`)이 길쭉한 세로 네모**로 바뀌었으면 성공입니다!

---

## 3단계: 음악 깔고 비트 찍고 빠른 컷 편집하기

### ① 배경음악 올리고 파형(소리 그래프) 크게 보기
1. 왼쪽 아래 `Project` 패널에서 **음악 파일**을 마우스 왼쪽 버튼으로 꾹 누른 채 끌어서(`드래그`), 오른쪽 아래 타임라인 **`A1` 줄 맨 왼쪽(`00:00:00`)** 에 놓습니다.
2. 타임라인이 너무 좁아서 잘 안 보일 때:
   - 키보드 **`+` 키**를 몇 번 누르면 타임라인이 가로로 넓게 확대됩니다. (`-` 키는 축소)
   - `A1` 글자 옆 빈 회색 부분을 마우스로 잡고 아래로 살짝 내리면 소리 울퉁불퉁한 파형(Waveform)이 크게 보입니다.

### ② 음악 비트(박자)에 깃발(마커) 꽂기
1. 키보드 **`Spacebar`(스페이스바)** 를 누르면 음악이 재생되고, 한 번 더 누르면 멈춥니다.
2. 음악이 나올 때 *"쿵! 짝! 쿵! 짝!"* 박자가 터지는 순간마다 키보드 **`M` 키**를 톡톡 누릅니다.
3. 타임라인 맨 위 눈금자에 초록색 작은 깃발(마커)들이 꽂힙니다. 이 깃발 위치마다 영상을 자를 거예요!

### ③ 영상 올리고 자르기 (필수 단축키 2개: `C`와 `V`)
1. `Project` 패널에서 **첫 번째 영상**을 마우스로 끌어서 타임라인 **`V1` 줄 맨 앞**에 놓습니다.
   - *(만약 "클립 설정이 시퀀스와 다릅니다" 창이 뜨면 **`Keep existing settings`(기존 설정 유지)** 클릭!)*
   - *(가로로 찍은 영상이라 위아래가 남는다면: 타임라인 영상 클릭 → 왼쪽 위 `Effect Controls` → `Motion` 왼쪽 `>` 클릭 → `Scale` 숫자를 마우스로 누른 채 오른쪽으로 드래그해서 `178` 정도로 키워 화면을 꽉 채우세요.)*
   - *(영상 자체의 시끄러운 현장음을 지우고 싶다면: 타임라인 영상에 마우스 오른쪽 클릭 → **`Unlink`(연결 해제)** 클릭 → 아래 초록색 오디오 부분만 클릭해서 키보드 **`Delete`** 누르기)*
2. 이제 키보드 **`C` 키**를 한 번 누릅니다. 마우스 커서가 **면도칼 모양**으로 바뀝니다.
3. 아까 꽂아둔 **초록 깃발(마커) 선**에 마우스를 대고 **왼쪽 클릭 한 번** 합니다. 영상이 두 동강 납니다!
4. **자르고 나서는 무조건 키보드 `V` 키**를 눌러서 마우스를 다시 **검은 화살표**로 돌립니다. *(이 습관이 정말 중요합니다!)*
5. 필요 없는 뒤쪽 영상 조각을 클릭한 뒤 키보드 **`Delete`** 를 눌러 지웁니다.
6. 두 번째 영상을 `Project` 패널에서 끌어다가 방금 자른 첫 번째 영상 **바로 오른쪽 끝에 딱 붙입니다.**

> **릴스 리듬 살리는 꿀팁 (`@yuyenwng` 스타일)**
> - 평상시 컷은 **0.5초~1초**(마커 간격)로 자릅니다.
> - 음악 비트가 빠르게 치고 나가는 구간에서는, 클립을 놓고 **키보드 오른쪽 화살표(`→`)를 딱 2~3번만 누른 뒤 `C`로 자르기**를 3~4번 연속 반복하세요. 0.1초짜리 초단기 컷들이 촤르륵 지나가면서 특유의 쫀득한 리듬이 살아납니다!

---

## 4단계: 리스본 릴스 핵심 효과 4가지 넣기

먼저 효과를 담을 **투명 필름(`Adjustment Layer`)** 을 하나 만들어 둡니다.

### 준비: 투명 필름(`Adjustment Layer`) 만들기
1. 왼쪽 아래 `Project` 패널 빈 공간을 한 번 클릭합니다.
2. 패널 맨 오른쪽 아래에 있는 **종이 모서리가 접힌 네모 아이콘(`New Item / 새 항목`)** 을 클릭합니다.
3. 메뉴에서 **`Adjustment Layer`(조정 레이어)** 를 클릭 → 크기가 `1080 x 1920`인지 확인 후 **`OK`** 클릭!
4. `Project` 패널에 `Adjustment Layer`라는 항목이 생겼습니다. 이걸 복사해서 아래 1번·2번 효과를 만들 거예요.

---

### 효과 ① `Flashes` (화면 넘어갈 때 번쩍! 플래시 터뜨리기)
1. 방금 만든 `Adjustment Layer`를 마우스로 끌어서, 타임라인 **`V2` 층**(영상 바로 위층)에서 **영상 A와 B가 만나는 경계선 위**에 올립니다.
2. 이 파란 막대의 양쪽 끝을 마우스로 잡고 안쪽으로 줄여서 **아주 얇은 막대(경계선 기준 앞 2프레임 + 뒤 3프레임, 총 4~5프레임 길이)** 로 만듭니다. *(키보드 `→` 1번 = 1프레임입니다!)*
3. 오른쪽 위(또는 왼쪽 아래) 탭에서 **`Effects`(효과)** 패널을 클릭합니다. *(안 보이면 상단 `Window` → `Effects`)*
4. `Effects` 검색창에 영어로 **`Exposure`** (또는 한글판이면 **`노출`** 또는 **`밝기`**) 를 검색합니다.
   - `Lumetri Color`가 편하면 **`Brightness & Contrast`(밝기 및 대비)** 를 써도 됩니다.
5. 찾은 **`Brightness & Contrast`** 를 마우스로 꾹 누른 채 끌어서, 방금 `V2` 층에 올려둔 **얇은 투명 필름 막대 위**에 떨어뜨립니다.
6. 그 `V2` 막대를 한 번 클릭하고 **왼쪽 위 `Effect Controls`(효과 컨트롤)** 를 봅니다.
   - `Brightness & Contrast` 아래 **`Brightness`(밝기)** 를 찾습니다.
   - 타임라인의 파란(또는 빨간) 세로 막대(재생 헤드)를 **플래시 막대의 맨 왼쪽 끝**에 두고, `Brightness` 왼쪽에 있는 **스톱워치(시계) 아이콘**을 클릭합니다. 숫자는 **`0`** 그대로 둡니다. (점이 하나 찍힙니다)
   - 재생 헤드를 **클립 A와 B가 바뀌는 정중앙**으로 옮기고, `Brightness` 숫자를 클릭해 **`130`** 을 입력 후 엔터!
   - 재생 헤드를 **플래시 막대의 맨 오른쪽 끝**으로 옮기고, 숫자를 다시 **`0`** 입력 후 엔터!
7. 스페이스바로 재생해 보세요! 화면이 바뀔 때 찰칵! 하고 하얗게 번쩍입니다.
8. **복붙 팁**: 완성된 플래시 막대를 **`Option`(윈도우 `Alt`) 키를 꾹 누른 채 마우스로 옆 컷 경계로 드래그**하면 통째로 복사됩니다!

---

### 효과 ② `Zooms` (휙! 당겨지며 속도감 있는 줌 전환)
1. `Project` 패널의 `Adjustment Layer`를 또 끌어서 **`V2` 층**의 다음 컷 경계선 위에 올립니다.
2. 이번에는 경계선 앞뒤로 **총 10프레임 정도(약 0.3초)** 길이로 자릅니다.
3. **`Effects`(효과)** 검색창에 **`Transform`** (한국어판: **`변형`**) 을 검색합니다.
   - *주의: `Motion` 말고, `Video Effects > Distort(왜곡)` 폴더 안에 있는 `Transform(변형)`을 고르세요!*
4. `Transform`을 마우스로 끌어서 방금 만든 `V2` 막대 위에 떨어뜨립니다.
5. 왼쪽 위 `Effect Controls`에서 `Transform` 설정을 만집니다:
   - 맨 아래쪽에 **`Use Composition's Shutter Angle` 체크박스를 클릭해서 체크 해제**합니다.
   - 바로 아래 **`Shutter Angle`(셔터 각도)** 숫자를 클릭해 **`180`** (더 강하게 번지게 하려면 `300`) 을 입력하고 엔터! *(이게 줌 될 때 쫙~ 번지는 모션 블러를 만들어 줍니다)*
   - 이제 막대 **맨 왼쪽 끝**에 재생 헤드를 두고, **`Scale`(비율)** 옆 **스톱워치 아이콘** 클릭(`100`).
   - 막대 **맨 오른쪽 끝**(또는 컷이 바뀌는 지점)으로 재생 헤드를 옮기고, `Scale` 숫자를 **`135`** 로 입력!
   - 오른쪽 키프레임 마름모 점 두 개를 마우스로 드래그해 파랗게 잡은 뒤, **마우스 오른쪽 클릭 → `Temporal Interpolation` → `Ease In` / `Ease Out`** 을 선택하면 움직임이 훨씬 쫀득해집니다.
6. 이것도 **`Option`(Alt) + 드래그**로 다른 컷 전환 위에 복사해 쓰세요!

---

### 효과 ③ `Wipe / Mask` (트램·건물 지나갈 때 화면 쓱 열리기)
초보자분께는 펜으로 일일이 따는 마스크보다 **`Linear Wipe`(선형 지우기)** 가 훨씬 쉽고 비슷하게 나옵니다!
1. 전환해서 나타날 **다음 영상 클립**을 `V1`이 아니라 한 층 위인 **`V2` 층**에 올리고, 이전 `V1` 영상의 끝부분과 0.3초(약 10프레임) 정도 겹치게 왼쪽으로 당겨 놓습니다.
2. `Effects` 검색창에 **`Linear Wipe`** (한국어판: **`선형 지우기`**) 를 검색해 **위층 `V2` 영상**에 드래그합니다.
3. `Effect Controls`에서 `Linear Wipe` 설정:
   - **`Wipe Angle`(지우기 각도)**: 트램이나 사람이 지나가는 방향에 맞춰 `90°` 또는 `-90°` 설정.
   - **`Feather`(페더)**: **`40`** 입력 (경계선이 칼처럼 딱 잘리지 않고 부드럽게 번짐).
   - `V2` 클립 **맨 앞**에서 `Transition Completion(전환 완료)` 스톱워치 클릭 후 **`100%`** 입력 → **10프레임 뒤**로 이동해 **`0%`** 입력!
4. 재생하면 앞 영상 위로 다음 영상이 쓱 닦이듯 열립니다!

---

### 효과 ④ `Scramble Text` (글자 무작위로 바뀌다 멈추는 자막)
1. 왼쪽 타임라인 옆 세로 도구 막대에서 **`T` 아이콘(문자 도구)** 클릭 → 오른쪽 위 TV 화면을 클릭해 원하는 글자 입력!
2. 가장 쉬운 왕초보 스크램블 꼼수:
   - 글자 클립을 1프레임~2프레임 길이로 아주 얇게 4조각 자릅니다.
   - 첫 3조각은 텍스트 내용을 `X9K#`, `L1$B`, `M4@Q` 처럼 의미 없는 알파벳으로 바꿔 적고, 마지막 4번째 긴 조각에만 진짜 제목(`LISBON`)을 적어둡니다.
   - 재생하면 글자가 촤르륵 섞였다가 딱 멈추는 효과가 10초 만에 완성됩니다!

## 5단계: 오디오 레이어링 (영상을 프로처럼 보이게 하는 비밀!)

무료 효과음 사이트(**Pixabay** 또는 **Mixkit** — 로그인 없이 무료 MP3 다운로드)에서 아래 4종류를 검색해 다운받아 `Project` 패널에 넣어주세요.

- **`camera click` / `shutter`** → `A2` 층에 올리고, **3단계에서 만든 초단기 컷(2~3프레임 컷)이 바뀌는 선 바로 아래**마다 `Option(Alt)+드래그`로 복사해서 딱딱 맞춰 놓습니다.
- **`whoosh`** → `A3` 층에 올리고, **4단계의 `Zoom` / `Wipe` 효과 막대 정중앙 아래**에 딱 맞춰 놓습니다.
- **`cinematic riser`** → `A4` 층에 올리고, 큰 장면 전환(또는 음악 하이라이트) **1~2초 전부터 전환 순간에 딱 끝나도록** 끝선을 맞춥니다.
- **`train ambience` / `city street`** → `A5` 층에 깔고, 클립 위 가로줄을 마우스로 아래로 내리거나(`Effect Controls > Volume > Level`), **`-22dB`** 정도로 아주 작고 은은하게 깝니다.
  *(소리 크기 조절 꿀팁: 음악 `A1`은 `-8dB` 내외, 효과음 `A2~A4`는 `-10dB` 내외, 현장음 `A5`는 `-22dB` 내외로 맞추면 귀가 안 아프고 쫀득합니다!)*

## 6단계: 필름 색감 입히고 인스타용 MP4 파일로 저장하기

### ① 한 번에 필름 색감 입히기
1. `Adjustment Layer`를 **`V3` 층(맨 위층)** 에 올리고, 오른쪽 끝을 마우스로 끌어 **영상 처음부터 끝까지 길게 늘립니다.**
2. 상단 메뉴 **`Window` → `Lumetri Color`(Lumetri 색상)** 을 엽니다.
3. 오른쪽에 뜬 창에서 **`Basic Correction`(기본 교정)** 을 눌러 아래처럼 조금만 만져도 리스본 필름 톤이 납니다:
   - `Temperature`(색온도): **`+10`** (살짝 따뜻한 햇살 느낌)
   - `Contrast`(대비): **`+15`**
   - `Highlights`(밝은 영역): **`-20`**
   - `Shadows`(어두운 영역): **`+10`**

### ② 완성 파일로 내보내기 (Export)
1. 타임라인 맨 앞(`00:00:00`)에 재생 헤드를 두고 키보드 **`I` 키**(시작점 표시), 영상 맨 끝에 재생 헤드를 두고 키보드 **`O` 키**(끝점 표시) 를 누릅니다.
2. 화면 맨 왼쪽 위 탭에서 **`Export`(내보내기)** 클릭 (단축키: `Cmd + M` / `Ctrl + M`).
3. **`File Name`** 에 완성 파일 이름(예: `리스본릴스_완성`)을 적고, **`Location`** 에서 저장할 폴더(바탕화면 등)를 고릅니다.
4. **`Format`(형식)** 이 **`H.264`** 로 되어 있는지 확인합니다.
5. **`Preset`(사전 설정)** 은 **`Match Source - Adaptive High Bitrate`** 로 둡니다. *(아래 요약에서 크기가 `1080 x 1920`인지 꼭 한 번 확인!)*
6. 오른쪽 아래 파란 **`Export`(내보내기)** 버튼을 누르면 완성입니다!
